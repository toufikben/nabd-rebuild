# نبض — مذكرتك الخاصة

**نبض (Nabd)** مذكرة يومية خاصة بالكامل تعمل على الجهاز فقط، بالعربية والإنجليزية. لا حسابات ولا خوادم ولا إعلانات ولا تتبع.

## ما في التطبيق

خمسة أقسام في الشريط السفلي:

| القسم | المحتوى |
|---|---|
| **اليوم** | تحية، سؤال اليوم للكتابة، السلسلة اليومية، تسجيل المزاج بنقرة، أدوات تهدئة، حكمة اليوم، آخر المدخلات |
| **المذكرة** | كل المدخلات مجمّعة بالشهر، بحث، تصفية بالمزاج، ومساحات الكتابة: الأحلام، الرسائل (غير المرسلة ورسائل المستقبل المختومة)، الامتنان، صندوق القلق، مذكرة الأجيال |
| **ممارسة** | ثماني جلسات تنفس موجّهة حسب الشعور (لكل منها صوت محيطي)، أدوات تهدئة، تحفيز وتحديات وإنجازات |
| **الحديقة** | بذور تنمو بالكتابة نفسها، حتى في الأيام الصعبة، بحد يومي |
| **رؤى** | إحصاءات، السلسلة، توزيع المزاج، طقس المشاعر، النبض الأسبوعي، الخريطة الحرارية، الأصداء، والرؤى المتقدمة (Pro) |

المحرر: حفظ تلقائي آمن، صور (مضغوطة ومشفّرة) ومعرض للتكبير، تسجيل صوتي مع تشغيل، إملاء صوتي، تاريخ قابل للتغيير، مزاج ووسوم.

## الخصوصية والأمان

- صناديق Hive مشفّرة بـ AES-256 ومفتاحها في Keystore/Keychain.
- الصور والتسجيلات مشفّرة على القرص بـ AES-256-GCM بمفتاح مستقل.
- قفل بالبصمة أو رمز 4–6 أرقام (PBKDF2)، مع حد محاولات يتضاعف ويبقى بعد إعادة التشغيل.
- لا نسخ سحابي تلقائي، ولا لقطات شاشة (`FLAG_SECURE`).
- نسخة احتياطية `.nabd` مشفّرة بكلمة مرور (AES-256-GCM على أجزاء، بلا حد للحجم) مع دمج حقيقي أو استبدال.
- تدوير مفتاح التشفير يصمد أمام الانقطاع ويُستكمل أو يُلغى عند الإقلاع التالي.

## الدخل

الكتابة مجانية دائمًا وبلا حد. **Pro** (شراء مدى الحياة؛ الاشتراكات مخفية حتى يتوفر خادم تحقق) يفتح: كل الجلسات، الرؤى المتقدمة، وتصدير PDF/Markdown. التفاصيل في [`docs/MONETIZATION_GUIDE.md`](docs/MONETIZATION_GUIDE.md).

## التطوير

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

- Flutter 3.27.0 / Dart 3.6.
- النصوص كلها في `lib/core/l10n/app_strings.dart` (عربي + إنجليزي)، واختبار يمنع نقص أي مفتاح أو كتابة نص مباشرة داخل الشاشات.
- لقطات تصميم للشاشات الرئيسية: `flutter test tool/screenshots_test.dart --dart-define=SHOTS_DIR=build/shots`.
- أصوات التطبيق الأصلية: `python3 scripts/synth_sounds.py` (انظر [`docs/SOUNDS_ATTRIBUTION.md`](docs/SOUNDS_ATTRIBUTION.md)).
- CI في `.github/workflows/android-build.yml`: تحليل واختبارات وبناء Debug لكل PR، وبناء Release موقّع عند التفعيل.
