# نبض — مذكرتك الخاصة

هذا المستودع الخاص يجمع مواصفات تطبيق **نبض (Nabd)** ومخرجات الكتل البرمجية المرفقة، مع أرشيف المصدر وتقارير التدقيق. التطبيق المقترح Flutter محلي أولًا، ويضم المذكرات والمزاج والحديقة والنسخ الاحتياطي والميزات النفسية والإحصاءات والأصول التسويقية.

## حالة التنفيذ

تم إنشاء المستودع الخاص ورفع الملفات المستخرجة من المرفقات مع الحفاظ على النصوص الأصلية. لم يُعلن نجاح بناء Flutter لأن بيئة التنفيذ الحالية لا تحتوي على Flutter أو Dart. توجد ملاحظات مانعة للبناء في [`BUILD_ERRORS.txt`](BUILD_ERRORS.txt)، وتوجد خريطة المصدر الكاملة في [`docs/SOURCE_FILE_MANIFEST.json`](docs/SOURCE_FILE_MANIFEST.json).

## سياسة المصدر

كل ملف معلّم `CREATE` أو `REPLACE` وله كتلة كاملة أُخرج إلى مساره. تعليمات `MODIFY` الجزئية محفوظة في manifest ولم تُطبّق عميانيًا حتى لا يُحذف أو يُستبدل أي سطر دون أساس كامل. عند وجود استبدال لاحق مكتمل، اعتُمد الاستبدال اللاحق وفق ترتيب المراحل.

## الخطوة التالية

بعد توفير Flutter SDK، يجب تشغيل `flutter pub get` ثم `flutter analyze` و`flutter test` وبناء Android/iOS. يجب أولًا معالجة الأسماء المركبة، وإضافة الملفات الأساسية المفقودة أو اعتماد مواصفة مكتملة لها، ثم مراجعة ادعاءات التشفير قبل النشر.
