📄 كود دمج الأصوات في شاشة البداية

لتفعيل تشغيل الصوت عند فتح التطبيق، أضف الحزم التالية إلى pubspec.yaml:

```yaml
dependencies:
  just_audio: ^0.9.36   # أو audioplayers: ^6.0.0
```

ثم في ملف splash_screen.dart، أضف الكود التالي:

```dart
import 'package:just_audio/just_audio.dart';

class SplashScreen extends StatefulWidget {
  // ...
}

class _SplashScreenState extends State<SplashScreen> {
  final AudioPlayer _audioPlayer = AudioPlayer();

  @override
  void initState() {
    super.initState();
    _playSplashSound();
    // ... باقي الكود
  }

  Future<void> _playSplashSound() async {
    try {
      // اختر الصوت بناءً على splashId أو من الإعدادات
      final soundId = Hive.box('settings').get('splash_sound', defaultValue: 'piano_gentle');
      await _audioPlayer.setAsset('assets/sounds/$soundId.mp3');
      await _audioPlayer.play();
    } catch (e) {
      // فشل صامت - لا يوقف التطبيق
    }
  }

  @override
  void dispose() {
    _audioPlayer.dispose();
    super.dispose();
  }
}
```

ملاحظة: يجب وضع ملفات الأصوات في المجلد assets/sounds/ وإضافتها إلى قسم assets في pubspec.yaml.

💰 ثانياً: نتائج البحث المعمق حول تحقيق الدخل

بعد فحص عشرات المصادر والبيانات من 75,000+ تطبيق، إليك أهم النتائج:

1. نموذج الاشتراك (Subscription) — المسيطر حالياً

الاشتراك هو النموذج الأكثر انتشاراً وربحية للتطبيقات التي تعتمد على العادات اليومية (مثل المذكرات). البيانات تظهر أن:

· التحويل إلى الدفع يصل إلى 12.1% مع الجدار الصلب (Hard Paywall) مقابل 2.2% مع النموذج المجاني (Freemium).
· قيمة العميل مدى الحياة (LTV) تصل إلى 49.30$** مع الجدار الصلب مقابل **24.24$ مع Freemium.
· ولكن: معدل الاسترداد (Refund) أعلى بنسبة 70% في الجدار الصلب.

2. الشراء لمرة واحدة (Lifetime) — نمو متسارع

· نموذج الشراء لمرة واحدة نما من 6.4% إلى 10.3% من نماذج تحقيق الدخل بين 2023 و2025.
· التسعير المثالي: من 2x إلى 12x السعر السنوي، وأفضل النتائج عند 5x أو أكثر.
· الخطر الأكبر: cannibalization — المستخدمون الأكثر ولاءً هم الأكثر احتمالاً لشراء Lifetime، مما يقلل الإيرادات المتكررة.

3. الإعلانات المكافأة (Rewarded Ads) — نموذج واعد

· الإعلانات المكافأة (يشاهد المستخدم إعلاناً مقابل ميزة) تزيد الإيرادات بنسبة 68% في بعض الحالات، مع معدل فتح 25%.
· تعمل بشكل أفضل عندما يكون هناك "شيء ذو قيمة" لفتحه (ميزة حصرية، محتوى، إلخ).

4. البيانات الحقيقية من تطبيقات المنافسين

📄 كود إضافي: نظام تحقيق الدخل الهجين

لتفعيل النموذج الهجين، أضف الكود التالي إلى مشروعك.

1. إعداد حزم الاشتراكات والإعلانات

أضف إلى pubspec.yaml:

```yaml

```

2. خدمة إدارة الاشتراكات

أنشئ ملف lib/services/monetization_service.dart:

```dart
import 'package:in_app_purchase/in_app_purchase.dart';
import 'package:hive_flutter/hive_flutter.dart';

class MonetizationService {
  final InAppPurchase _iap = InAppPurchase.instance;
  List<ProductDetails> _products = [];

  // معرفات المنتجات (يجب إنشاؤها في Play Console و App Store)
  static const String proMonthlyId = 'nabd_pro_monthly';
  static const String proYearlyId = 'nabd_pro_yearly';
  static const String lifetimeId = 'nabd_lifetime';

  Future<void> initialize() async {
    final available = await _iap.isAvailable();
    if (!available) return;

    final response = await _iap.queryProductDetails({proMonthlyId, proYearlyId, lifetimeId});
    _products = response.productDetails;

    _iap.purchaseStream.listen(_onPurchaseUpdate);
  }

  Future<void> buy(ProductDetails product) async {
    final param = PurchaseParam(productDetails: product);
    if (product.id == lifetimeId) {
      await _iap.buyNonConsumable(purchaseParam: param);
    } else {
      await _iap.buyNonConsumable(purchaseParam: param);
    }
  }

  void _onPurchaseUpdate(List<PurchaseDetails> purchases) {
    for (final purchase in purchases) {
      if (purchase.status == PurchaseStatus.purchased || 
          purchase.status == PurchaseStatus.restored) {
        // منح الميزة
        Hive.box('settings').put('isPro', true);
        if (purchase.productID == lifetimeId) {
          Hive.box('settings').put('isLifetime', true);
        }
      }
      if (purchase.pendingCompletePurchase) {
        _iap.completePurchase(purchase);
      }
    }
  }

  Future<void> restorePurchases() => _iap.restorePurchases();
}
```

3. خدمة الإعلانات المكافأة

أنشئ ملف lib/services/rewarded_ad_service.dart:

```dart
import 'package:google_mobile_ads/google_mobile_ads.dart';

class RewardedAdService {
  RewardedAd? _rewardedAd;
  bool _isLoading = false;

  static const String _adUnitId = 'ca-app-pub-XXXXXXXXXXXXXXXX/YYYYYYYYYY'; // من AdMob

  void loadAd() {
    if (_isLoading || _rewardedAd != null) return;
    _isLoading = true;

    RewardedAd.load(
      adUnitId: _adUnitId,
      request: const AdRequest(),
      rewardedAdLoadCallback: RewardedAdLoadCallback(
        onAdLoaded: (ad) {
          _rewardedAd = ad;
          _isLoading = false;
        },
        onAdFailedToLoad: (error) {
          _isLoading = false;
        },
      ),
    );
  }

  void showAd({required VoidCallback onReward}) {
    if (_rewardedAd == null) return;

    _rewardedAd!.fullScreenContentCallback = FullScreenContentCallback(
      onAdDismissedFullScreenContent: (ad) {
        ad.dispose();
        _rewardedAd = null;
        loadAd(); // تحميل الإعلان التالي
      },
    );

    _rewardedAd!.show(onUserEarnedReward: (_, reward) {
      onReward(); // منح المكافأة
    });
  }
}
```
