📄 الملف 97: scripts/generate_screenshots.sh

```bash
#!/bin/bash
# generate_screenshots.sh — يحول SVGs إلى PNGs للمتجر.

set -e

SCREENSHOTS_DIR="assets/store/screenshots"
OUTPUT_DIR="assets/store/output"

mkdir -p "$OUTPUT_DIR"

echo "📱 Generating store screenshots..."

for svg in "$SCREENSHOTS_DIR"/*.svg; do
  filename=$(basename "$svg" .svg)
  echo "→ $filename.png (1080×1920)"
  svgexport "$svg" "$OUTPUT_DIR/$filename.png" 1080:1920
done

echo ""
echo "✅ Screenshots created!"
ls -lh "$OUTPUT_DIR"/*.png
```

## Quick Facts

| | |
| :--- | :--- |

| **Privacy** | 100% local, no cloud |
| **Launch Date** | Q4 2026 |

## One-Liner
> "مذكرتك الخاصة التي تنمو معك — 100% محلية، بدون إنترنت، مع حديقة نفسية."

## Short Description (50 words)
نبض تطبيق مذكرات فريد يحوّل الكتابة اليومية إلى رحلة نمو. اختر بذرة، اكتب، وشاهد شجرتك تنمو. مع طقس المزاج، رادار المشاعر، ورسائل لمستقبلك. كل شيء محلي 100% — لا خوادم، لا تتبع، لا إعلانات.

## Long Description (200 words)
نبض ليس مجرد تطبيق مذكرات. إنه رفيق نفسي كامل.

🌱 **حديقة البذور**: اختر بذرة (حب، فرح، سلام...) وكل مذكرة إيجابية تُنمّي شجرتك عبر 5 مراحل: بذرة → برعم → شتلة → شجرة → ازدهار.

🌤️ **طقس المزاج**: مشاعرك كطقس مرئي — مشمس، غائم، ممطر، عاصف. توقعات 7 أيام ورادار 6 أبعاد.

🧠 **صحة نفسية**: أطلق همّك بكتابته، عزله في صندوق القلق، تنفس قبل الكتابة، وسجّل أحلامك.

💌 **للمستقبل**: رسائل مقفلة بزمن (شهر، سنة، 5 سنوات)، كبسولات زمنية، ورسائل لن تُرسل أبداً.

📊 **إحصائيات**: سحابة الكلمات، Year in Review (بأسلوب Spotify Wrapped)، خريطة حرارية، وملخصات ذكية.

🏆 **تحفيز**: 10 إنجازات، 5 تحديات، اقتباس يومي، وسلاسل كتابة.

🔒 **خصوصية مطلقة**: تشفير AES-256، قفل بيومتري، لا رفع للصور، لا تتبع، لا إعلانات.

## Founder Quote
> "بنيت نبض لأنني تعبت من تطبيقات المذكرات التي تطلب حساباً وترفع بياناتي للخوادم. أردت شيئاً يبقى ملكي — وحدي." — مطور نبض
