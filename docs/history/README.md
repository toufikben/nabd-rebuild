# أرشيف تاريخي

مستندات كُتبت في مراحل سابقة من بناء نبض (الاستخراج من المرفقات، سجلات البناء الأولى، تدقيقات سبتمبر 2026).
تُحفظ كسجل لما حدث، لكنها **لا تصف الحالة الحالية** وبعض ما فيها لم يعد صحيحًا
(مثل أخطاء التحليل المذكورة، أو حد السبع مدخلات، أو AdMob).
